# Results

This directory contains a transcription of measurements shared in conversation, but no machine-generated evaluation reports from the original run. The repository does not include the fixed FAQ corpus, evaluation queries, or embedding caches, so its published code alone cannot reproduce or verify those measurements.

Run the commands in the project README with the fixed input data to generate `development_report.json`, `holdout_report.json`, and `final_report.md`. Do not interpret a new run as the original holdout measurement. If the original files become available, compare their inputs, config, cache hashes, and recorded results with the transcription before publishing them as reproducible artifacts.
