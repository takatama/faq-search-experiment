# Results

This directory intentionally contains no evaluation reports. The repository does not include the fixed FAQ corpus, evaluation queries, or embedding caches, so its published code alone cannot reproduce or verify the previously reported measurements.

Run the commands in the project README with the fixed input data to generate `development_report.json`, `holdout_report.json`, and `final_report.md`. Keep the original evaluation run and its model settings as a separate, versioned record. Do not interpret a new run as the original holdout measurement.
