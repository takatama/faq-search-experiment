The reported evaluation used a fixed holdout of 360 queries. The reported models were `gemini-3.5-flash-lite` for aliases and `gemini-embedding-2` (3072 dimensions) for embeddings; the frozen gate was `{"minTop1":0,"minMargin":0.02,"minCoverage":0,"minLength":3}`. The local timings used cached embeddings and exclude API latency, input reading, and index construction. The source code currently in this repository has different default models and an unfrozen gate, and should not be presented as the exact implementation of the reported run.
